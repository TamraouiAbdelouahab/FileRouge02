Voici une proposition d'**indicateurs de performance (KPI)** pertinents pour votre **package "Justification d'absence"**, suivie d’un **exemple de tableau de bord clair et fonctionnel** adapté au **Sprint 1**.

---

### 📊 **Indicateurs de performance (KPI)**

| Indicateur                            | Description                                                                 |
|--------------------------------------|-----------------------------------------------------------------------------|
| 🔢 Nombre total de justificatifs     | Tous les justificatifs soumis, qu'ils soient traités ou non.              |
| ⏳ Justificatifs en attente          | Nombre de justificatifs non encore traités par le responsable.            |
| ✅ Justificatifs acceptés            | Nombre et pourcentage de justificatifs validés.                           |
| ❌ Justificatifs rejetés             | Nombre et pourcentage de justificatifs refusés.                           |
| 🕒 Délai moyen de traitement         | Temps moyen entre la soumission et la décision (en jours/heures).         |
| 📥 Nouveaux justificatifs reçus     | Nombre de justificatifs déposés dans les 7 derniers jours.                |
| 👤 Stagiaires les plus actifs        | Stagiaires ayant soumis le plus de justificatifs.                         |

---

### 📋 **Proposition de Tableau de Bord (Sprint 1)**

| Zone              | Contenu                                                                 |
|------------------|-------------------------------------------------------------------------|
| **Header**        | Titre : *Tableau de bord – Justifications d'absence* + filtre par date |
| **Statistiques clés (cartes)** |  
| - Total reçus       | `132` justificatifs |  
| - En attente         | `24` en attente de traitement |  
| - Acceptés           | `92` validés (`70%`) |  
| - Rejetés            | `16` refusés (`12%`) |  
| - Délai moyen        | `1,8 jours` |
| **Graphique circulaire** | Répartition des statuts (Acceptés / Rejetés / En attente) |
| **Liste dynamique** | Tableau des justificatifs récents avec : nom du stagiaire, date de dépôt, statut, action |
| **Top 5 stagiaires** | Liste des stagiaires ayant le plus soumis de justificatifs |
